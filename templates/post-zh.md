# 中文社区帖模板

适用于 V2EX、掘金、知乎、即刻、小红书。各平台删减，不要整篇贴。

## 结构

1. 一句定位——这东西是什么，不解释动机
2. 一句话说清最值得看的一点
3. 其余能力平铺，不写实现
4. 安装方式和仓库地址
5. 素材/授权说明（有第三方美术时必须有）

## 写法

- 不用第一人称抒情。"我嫌它太丑所以做了一个"这种句子，读起来像论坛帖不像项目介绍。
- 不写宿主的内部实现（字段名、类名、框架 API）。讲现象和结论，不讲怎么做到的。
- 不排比。连续三段同样的句式最像机器写的。
- 吹要落在具体的、可验证的事实上，不落在形容词上。

## 骨架

```
<一句定位>

<最值得看的一点，两三句>

<其余能力，一段或一个短列表>

npm i <package> · github.com/<owner>/<repo>

<素材来源与授权，一句话>
```
