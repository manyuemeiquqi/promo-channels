# English post template

For Reddit, Hacker News (Show HN), X, and GitHub Discussions.

## Structure

1. One line: what it is.
2. The single most interesting thing, in two or three sentences.
3. Everything else, flat — no implementation detail.
4. Install command and repo URL.

## Writing notes

- No first-person confessionals. "I got tired of how it looked" reads like a forum post, not a project announcement.
- Don't expose the host's internals (field names, class names, framework APIs). Describe behaviour and outcome, not mechanism.
- Avoid the "not X, but Y" construction more than once. It is the most recognisable machine-written cadence in English too.
- Claims should be checkable. "Six stars light up while it runs" beats "a delightful experience".

## Skeleton

```
<one-line positioning>

<the one thing worth looking at, 2-3 sentences>

<everything else, one paragraph or a short list>

npm i <package> · github.com/<owner>/<repo>

<asset attribution, one line, if third-party art is involved>
```
